# Admin tools

Tools for test servers: administrator actions and a command file run on the server console. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/admin-tools.toml`, written on first start; its
log is `logs/enshwick/mods/admin-tools.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-admin-tools/releases/tag/dev).
